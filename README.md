# nachgerechnet

Videos, die die Finanzen von Film- und Serienfiguren nachrechnen.

## Ordner
- `reference/` Referenzvideo (nicht im Repo)
- `assets/` Figuren, Szenen, Props, Sounds
- `styles/` eine JSON pro Serie
- `src/` Remotion-Projekt mit den Szenen-Komponenten
- `output/` fertige Videos (nicht im Repo)
